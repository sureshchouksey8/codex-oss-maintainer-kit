# Code of Conduct

This project follows a simple standard: be respectful, specific, and useful.

Expected behavior:

- discuss code and ideas without personal attacks
- assume maintainers and contributors have limited time
- keep bug reports reproducible when possible
- avoid spam, harassment, and low-effort automated submissions

Unacceptable behavior includes harassment, abusive language, doxxing, threats, or deliberately disruptive conduct.

Maintainers may remove comments, close issues, or block users who make the project unsafe or unproductive.
